# Docs site

Fumadocs + Next.js, same stack as [Tailrace docs](https://www.tailrace.dev/docs).

```bash
cd website
pnpm install
pnpm dev
```

Open [http://localhost:3000/docs](http://localhost:3000/docs).

`pnpm build` is the production check. Set the Vercel root directory to `website` when you deploy.
